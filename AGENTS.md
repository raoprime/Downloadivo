# Workspace Rules — Downloadivo Studio Edition

## 1. Visual & Aesthetic Standards (Apple / Linear / Cred Tier)
- **Dark Mode Precision**: Use deep obsidian backgrounds (`#070709` to `#0D0E12`), subtle 1px translucent borders (`rgba(255,255,255,0.08)` / `0x14FFFFFF`), and soft ambient radial mesh blurs.
- **Strict Anti-Slop Ban**: NEVER generate procedural 2D/3D Canvas shapes, raw SVG orbital circles, tacky neon glows, or emoji-stuffed cards.
- **Typography & Card Discipline**: Numbers and titles inside bento grid cards MUST never wrap awkwardly across lines. Use `tabular-nums` / fixed font features, crisp hierarchy, and consistent 4px grid padding.

## 2. Agent Freedom & Skill Protocol
- Full autonomy to inspect the codebase, install necessary animation packages (`lottie-compose` / `lottie-react` / `@rive-app/react-canvas` / `framer-motion` or `react-native-reanimated`), and run `.agents/skills/` scripts (`ui-ux-pro-max` and `unslop`) before writing UI code.
- Always verify responsive mobile alignment (360px–430px width) in the preview browser or emulator before marking a task complete.
