# ⚡ Downloadivo — Universal High-Speed Media Downloader

Downloadivo is a production-grade, high-performance media downloader supporting **8K, 4K, 1080p video, high-bitrate audio, Instagram Reels, Carousels, Stories, Profiles, and YouTube Community posts**.

## 🚀 Features
- **8K / 4K / 60FPS / HDR** support with multi-stream FFmpeg merging.
- **Batch Download Queue** with real-time ETA and live speed meters.
- **Instagram & YouTube Specialist** (Reels, Stories, Audio, DP, Community Posts).
- **Universal Mobile & Browser Streaming** (`/file/{task_id}`).
- **Ephemeral Auto-Pruning Storage** (30-minute retention TTL, 0 storage footprint).
- **100% Free & Open-Source**.

## 🛠️ Tech Stack
- **FastAPI** + **Uvicorn** + **Gradio**
- **yt-dlp** + **Instaloader**
- **FFmpeg** + **Node.js**
- **Pure Native Modern Dark UI**
